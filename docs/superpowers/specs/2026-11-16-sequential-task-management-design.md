# 时序任务管理设计说明

**产品目标：** 建立可长期保存本机任务数据、支持时间安排与依赖关系的 Tauri 2 单窗口桌面应用。

**功能边界：** 支持任务新增、编辑、删除、日期调整、进度修改、前置依赖、备注和状态管理。不包含账号、权限、角色、云同步和多人协作。

## 架构

前端使用原生 HTML、CSS、JavaScript 和 Vite，直接引入同级甘特图组件。Tauri 通过自定义 Rust 命令访问 SQLite，不运行本地 HTTP 后端。数据库连接由 Rust 管理，前端通过任务数据服务完成读写和自动保存。

```text
前端界面与甘特图
        |
        v
任务数据服务
        |
        v
Tauri 命令 -> Rust 数据层 -> SQLite
```

数据库文件位于 Tauri 应用数据目录。数据库采用本机轻量结构，只保留必要字段和默认值，不包含账号、角色、授权、外键或严格检查约束。

## 数据模型

任务表保存名称、状态、日期、进度、依赖、备注、排序和时间戳。状态包括完成、未完成、延期和搁置，新建任务默认为未完成。日期采用 `YYYY-MM-DD`，依赖采用 JSON 字符串数组。

## 交互设计

主窗口由项目时序控制台、状态统计和全高甘特图组成。任务编辑采用原生弹窗，包含任务名称、日期、状态、进度、前置任务和备注。拖动日期或进度后自动保存，任务操作按顺序写入数据库。

## 视觉设计

界面采用深色控制台式视觉，使用青绿色信息层、橙色关键强调和克制的玻璃面板。标题字体为 Exo，日期字体为 Roboto Mono，中文字体回退为微软雅黑。甘特图作为主要视觉元素，状态同时使用颜色和文字表达。

## 启动动画

桌面窗口背景与页面底色保持一致。启动时展示项目时序引擎动画，包括标志绘制、进度展开和界面淡入。系统启用减少动态效果时，关闭非必要动画。

## 验证

前端测试覆盖任务映射、状态统计、日期处理和写入顺序。Rust 测试覆盖数据库初始化、旧库升级、任务读写、日期更新、进度更新、依赖清理和重启持久化。交付前执行前端测试、Rust 测试和前端生产构建。
