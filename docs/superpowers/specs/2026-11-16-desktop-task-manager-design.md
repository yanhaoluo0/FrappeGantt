# 极简桌面任务管理工具设计

**目标：** 在不修改现有 `gantt` 组件源码的前提下，建立可长期保存本机任务的 Tauri 2 单窗口桌面应用。

**边界：** 第一版只支持任务的新增、编辑、删除、日期拖动、进度修改、前置依赖和备注。不包含账号、权限、角色、云同步、多人协作、通知和复杂项目管理。

## 架构

前端采用原生 HTML、CSS、JavaScript 和 Vite，直接引入同级 `gantt/src/index.js`。Tauri 通过自定义 Rust 命令访问 SQLite，不运行本地 HTTP 后端。数据库连接由 Rust 管理，前端只调用 `list_tasks`、`save_task`、`delete_task`、`update_task_dates` 和 `update_task_progress`。

```text
HTML/CSS/JS + Frappe Gantt
          |
          v
      TaskStore
          |
          v
Tauri invoke -> Rust DB module -> tasks.db
```

数据库文件位于 Tauri 的应用数据目录。SQLite 保持宽松：只设置主键和必要默认值，不增加外键、检查约束、用户、角色或授权表。

## 数据模型

`tasks` 表保存任务名称、日期、进度、依赖 JSON、备注、排序和时间戳。日期使用 `YYYY-MM-DD`，依赖使用 JSON 字符串数组。应用首次启动只创建表，不写入演示任务。

## 交互

主窗口只显示标题、保存状态、“新建任务”按钮和甘特图。任务弹窗包含名称、开始日期、结束日期、进度、前置任务和备注。双击任务打开编辑弹窗。拖动日期和拖动进度后自动保存，保存请求按顺序执行。保存失败时显示可重试状态，不回写虚假的成功提示。

## 视觉方向

界面使用浅灰绿工作底、墨绿色主色和琥珀色强调色。标题采用 Windows 自带的 Bahnschrift，正文采用 Segoe UI，日期使用等宽字体。布局只保留顶部工具栏和整页时间线，甘特图本身作为主要视觉元素。键盘焦点使用清晰的琥珀色轮廓，并遵循减少动态效果的偏好。

## 验证

Rust 单元测试覆盖建表、任务读写、更新日期、更新进度和删除。JavaScript 单元测试覆盖数据库对象映射、日期格式化和写入队列顺序。最终验证包括 Vite 构建、Rust 测试、Tauri 构建以及实际启动应用。
