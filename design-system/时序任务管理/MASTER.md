# 时序任务管理设计系统

**产品类型：** 本机桌面生产力工具  
**视觉方向：** 深色控制台、精准时间线、克制的科技感  
**核心原则：** 数据优先、低干扰、清晰的层级、短促而有意义的动效

## 颜色

| 语义 | 色值 | 用途 |
|---|---|---|
| 深背景 | `#06131a` | 应用底色 |
| 抬高表面 | `#0b2029` | 面板与弹窗 |
| 主文字 | `#e8f7f4` | 标题与正文 |
| 次文字 | `#91aaa6` | 辅助信息 |
| 主色 | `#14b8a6` | 焦点、数据与主操作 |
| 深主色 | `#0f766e` | 主按钮背景 |
| 强调色 | `#fb923c` | 进度手柄与关键强调 |
| 完成 | `#34d399` | 完成任务 |
| 未完成 | `#fbbf24` | 默认任务状态 |
| 延期 | `#fb7185` | 延期任务 |
| 搁置 | `#94a3b8` | 搁置任务 |

主文字与深背景对比度约 17:1，次文字约 7.6:1，主按钮文字约 6.8:1。

## 字体

- 标题与控件：Exo
- 日期与数据：Roboto Mono
- 中文回退：Microsoft YaHei UI
- 字体文件随应用本地打包，不依赖在线字体服务

## 布局

单窗口结构依次为品牌工具头、计划状态栏和全高甘特图。工具栏保持单行，窄窗口下状态统计自动换行。甘特图使用剩余全部高度，任务较多时只允许图内滚动。

## 组件

主按钮高度不低于 44px，使用青绿色渐变与轻量光晕。次级按钮透明背景，悬停时仅改变表面色。表单输入使用深色表面、可见标签和 3px 青色焦点环。弹窗使用深色半透明遮罩和 10px 进入位移。

任务状态始终同时提供颜色和文字，不依赖颜色单独表达含义。状态统计固定在图表面板上方，方便快速判断总体情况。

## 启动动画

桌面窗口背景与页面底色一致，避免启动白屏。页面加载时显示项目时序引擎启动层：标志线条绘制、进度条横向展开，随后启动层淡出、主界面由下方轻移进入。动画仅在数据准备好后结束。

## 动效

- 微交互：`180ms`
- 启动层退出：`360ms`
- 主界面进入：`480ms`
- 弹窗进入：`280ms`
- 缓动：`cubic-bezier(0.16, 1, 0.3, 1)`
- 启用减少动态效果时关闭非必要动画

## 可访问性

- 所有关键按钮和表单控件具有可见焦点
- 主操作高度不低于 44px
- 使用语义化 `label`、`fieldset`、`legend` 和 `role="status"`
- 页面不得产生整体横向滚动
- 不依赖单一颜色表达任务状态
